# 配置存储

- **实现**: `server/utils/store.ts`
- **类型**: [reference/数据模型.md](../../reference/数据模型.md)

实例组与实例配置的持久化层，文件形态 JSON，无数据库。

## 文件

| 项 | 值 |
|----|-----|
| 路径 | `server/data/groups.json`（常量 `DATA_FILE`） |
| 形态 | `InstanceGroup[]` |
| 编码 | UTF-8 JSON，缩进 2 |

进程首次访问若文件不存在：建目录并写入**仅含默认分组**的初始数组。

## 默认分组

`createDefaultGroup()`：`isDefault: true`，置顶展示，删除接口拒绝删除默认组。

## 并发写

```text
writeChain: Promise
withLock(fn)  # 所有写操作串行挂在链上
```

写路径（create/update/delete group、add/update/delete/duplicate instance、import）均 `withLock`；读路径直接读文件。失败的 promise 不阻断后续写（`catch(() => {})` 吞掉后继依赖）。

## 操作面

| 导出函数 | 作用 |
|----------|------|
| `getGroups` / `getGroup` | 读 |
| `createGroup` / `updateGroup` / `deleteGroup` | 分组维护 |
| `addInstance` / `updateInstance` / `deleteInstance` / `duplicateInstance` | 实例维护 |
| `exportGroups` | 导出全量 |
| `importGroups` | 按 id 合并（有则更新无则新增），返回 `{ added, updated }` |

实例 id / 分组 id 在写入时生成；`duplicateInstance` 在源实例后插入副本，名称追加 `(副本)`。

## 密钥

`secretKey` 明文存于 `groups.json`；该文件已被 gitignore，备份与权限由部署方负责。
