# 对象浏览

- **路由**: `/browse`
- **实现**: `app/pages/browse/index.vue`、`app/components/browse-*.vue`、`app/types/browse`

## 布局

- **左栏实例树**：分组折叠 + 实例节点；点击实例打开标签
- **主区**
  - **标签栏**：每个已打开实例一个标签，可关闭、切换
  - **Bucket 列表** 或 **对象面板**（进入 bucket 后）
  - 工具：上传、下载、删除、复制/移动、复制路径等（随选择启用）

## 标签与路由同步

| 行为 | 规则 |
|------|------|
| 打开实例 | 已有标签则激活；否则新建并加载 bucket |
| 关闭标签 | 激活相邻标签或清空 |
| URL | `?tabs=id1,id2&active=<id>`；`?instance=<id>` 会规范成 tabs/active |
| 刷新 | 从 URL 恢复标签并重新加载 |

仅 **enabled** 实例可被打开。

## 浏览

- Bucket 列表：名称、创建时间；进入后展示对象
- 对象列表：虚拟目录（前缀）+ 对象行；名称过长省略 + tooltip（完整 key）
- 无限滚动加载下一页（ListObjectsV2 分页）
- **复制路径**：`bucket/key` 写入剪贴板（HTTP 下回退 `execCommand`）

## 预览

点击预览 → 弹窗按类型渲染：

| 类型 | 行为 |
|------|------|
| 图片 / 视频 / 音频 | inline；媒体下载支持 Range |
| PDF | 内嵌 |
| 文本 | 拉取内容；**>2MB** 提示「请下载后查看」 |

类型由扩展名推断（`getPreviewType`）。

## 上传

1. 选择文件 / 文件夹（保留相对路径）
2. 弹窗阶段：`select → staging → uploading → done`
   - staging：XHR 逐文件暂存，百分比；可取消（回 select）
   - uploading：提交任务 + SSE；**可关闭弹窗后台继续**
   - done：结果列表；可 **重试失败项**（重新暂存 + 新任务）
3. staging 中禁止关闭弹窗；文件夹内文件聚合显示

## 删除

选择对象/文件夹 → 确认弹窗先 **预览** 将删除的 key，再执行；支持批量（与 API 批次一致）。

## 复制 / 移动

弹窗选择目标实例 + bucket + 前缀；源 bucket 在目标列表中禁用（同实例时）。  
提交后进入任务（可后台）；移动含删源阶段，UI 显示删源状态。

## 多选

对象面板多选（checkbox）；批量下载 ZIP、批量删除等与单选操作区联动。
