# 文件批量分发

入口：顶栏 **文件分发**（`/dispatch`）。

将本地文件/文件夹推送到**多个 S3 实例**。

## 流程

```text
选择文件 → 选择目标（实例 + bucket + 前缀）→ 暂存 → 提交分发 → 任务队列执行
```

## 选择文件

- **添加文件** / **添加文件夹**（保留目录结构）
- 文件夹内相对路径作为 `objectKey`
- 同名 objectKey 后选覆盖先选

## 选择目标

- 左侧实例树：仅显示 **enabled** 实例
- 每个选中实例指定 **bucket**（可组级批量设相同 bucket）
- 可选全局 **目标前缀**；最终 key = `prefix/objectKey`

## 执行与进度

- **暂存阶段**：XHR 逐文件传到后端磁盘，有百分比；失败单文件不阻断
- **分发阶段**：后端任务，实例维度并发（默认 5），实例内文件串行
- 进度卡片按实例折叠展示；可 **后台继续** / **取消**

## 上传策略

任意大小均为**单次 PUT**（`readFile` + `PutObject`）。不使用 S3 Multipart。超大文件内存占用约等于文件大小。

## 失败与重试

- 单文件失败不影响其他实例/文件
- 完成后可对含失败的实例 **重试**（重新暂存失败文件，收窄到单实例）
- 任务查看器中的历史任务不提供重试（本地原文件可能已不在）

## 取消

- 已上传对象保留
- 未开始文件标「已跳过」
- 正在传输的单次 PUT 跑完即停

## 注意

- 暂存阶段离开页面会中断该阶段；已暂存文件由 TTL 清理
- 分发阶段关闭页面不影响（后端继续）
