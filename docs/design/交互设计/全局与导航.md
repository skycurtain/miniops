# 全局与导航

- **实现**: `app/layouts/default.vue`、`app/components/app-navbar.vue`

## 布局

`NuxtDashboardGroup`：

- **左侧边栏**（可折叠、可拖宽，`min-size=12` / `default-size=16`）
  - 头部：图标 + 产品名 `miniops`（折叠后仅图标）
  - 导航：`实例管理` → `/manage`，`实例访问` → `/browse`，`文件分发` → `/dispatch`
  - 折叠项带 tooltip
- **主区**：各页面自带 `AppNavbar` + 内容

## 页头 AppNavbar

| 区域 | 内容 |
|------|------|
| leading | 文案「S3 对象存储运维平台」（`lg` 以下隐藏） |
| title | 各页标题（实例管理 / 实例访问 / 文件分发） |
| right | **暂存文件管理**、**任务查看器**、主题切换 |

右上角三枚入口**全局常驻**，与当前路由无关。

## 路由

| 路径 | 页面 | 说明 |
|------|------|------|
| `/manage` | 实例管理 | 根路径 `/` 重定向至此 |
| `/browse` | 实例访问 | 支持 `?instance=<id>` / `?tabs=&active=` |
| `/dispatch` | 文件分发 | |

## Toast

操作反馈统一 `useToast().add({ title, description?, color: success|error|warning })`。

## 无障碍 / 细节

- 色彩模式跟随 Nuxt ColorMode（默认 light）
- 侧边栏折叠状态由 `NuxtDashboardSidebarCollapse` 控制
