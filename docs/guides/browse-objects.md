# 对象浏览与操作

入口：顶栏 **实例访问**（`/browse`），或从实例管理跳转。

## 界面

- **左栏**：实例树（分组 + 实例）
- **主区**：Bucket 列表 → 对象列表（虚拟文件夹）→ 预览/操作

支持多标签：同时打开多个实例。

## 浏览

- 对象列表按 `prefix/` 虚拟目录展示
- 无限滚动加载；名称过长省略 + tooltip 显示完整 key
- **复制路径**：复制 `bucket/key` 到剪贴板

## 上传

1. 进入目标路径 → **上传**
2. 可选文件或文件夹（保留相对目录）
3. 两阶段：先暂存到后端磁盘，再提交上传任务
4. 上传中可后台继续，任务在查看器中跟踪

最终 key = `当前前缀/objectKey`。同名覆盖，不弹确认。

## 下载

- 单文件流式下载（支持视频 Range）
- 多选/文件夹可 **ZIP 批量下载**（上限 1000 个对象，`DOWNLOAD_MAX_OBJECTS`）

## 预览

- 图片 / 视频 / 音频 / PDF inline
- 文本类拉取内容（**≤2MB**，更大提示下载后查看）
- 视频/音频下载走 Range（206）

## 删除

- 支持对象与文件夹前缀
- 先 **预览** 再确认；前缀删除为递归删除
- 单次选择/删除对象上限约 1000（与 S3 DeleteObjects 批大小一致）

## 复制 / 移动

- 目标：同实例其他路径，或其他实例
- **复制**：同 endpoint 用服务端 CopyObject；跨实例 Get→Put
- **移动**：复制成功后删源（非原子；中途失败可能出现双副本）
- 走统一任务，可后台、可取消
- 递归展开文件夹有对象数上限（默认 10000，见环境变量）

## 路径安全

objectKey 经服务端清洗（防路径遍历）：反斜杠归一化、去段首点、过滤 `..`。
