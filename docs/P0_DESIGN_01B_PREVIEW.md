# 对象预览交互设计文档

> **目标**：在对象浏览器（提议 1）中支持内容预览，用户点击「预览」即可在平台内查看图片、视频、音频、PDF 和文本内容，无需下载到本地。
>
> 本文档是 `P0_DESIGN_01_BROWSER.md` 的补充，聚焦预览功能的交互细节。

---

## 一、设计目标与约束

### 1.1 解决的痛点

对象浏览器已支持浏览和下载，但用户想确认文件内容时必须下载到本地再打开。运维场景中频繁需要"扫一眼"配置文件、查看图片是否正确、确认 PDF 内容，下载-打开-删除的循环很低效。

### 1.2 设计原则

- **复用已有后端能力**：预览与下载本质是同一个 GetObject 流式代理，区别仅在 `Content-Disposition` 头（`inline` vs `attachment`）。后端零新增签名代码。
- **浏览器原生渲染优先**：图片/视频/音频/PDF 用浏览器原生标签（`<img>`/`<video>`/`<audio>`/`<iframe>`）渲染，后端不转码、不缓冲。
- **文本安全展示**：文本类文件 fetch 内容后用 `<pre>` 展示，Vue 模板插值自动转义，防 XSS。
- **格式不可预览时优雅降级**：不支持的格式隐藏预览按钮，或提示"该格式不支持浏览器预览，请下载"。

### 1.3 已确认的决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| 弹窗形式 | Drawer 侧抽屉 | 宽度大，适合看代码和长文本，不影响列表上下文 |
| 类型范围 | 全类型（图片/视频/音频/PDF/文本） | 覆盖所有常见运维场景 |
| 后端改动 | 复用 download 路由加 `?inline=1` 参数 | 零新增路由，零新增签名代码 |
| 文本大小上限 | 2MB | 超大日志文件 fetch 到浏览器会卡顿，超限提示下载 |
| 语法高亮 | 第一期不做，纯 `<pre>` 展示 | 避免引入高亮库增加包体积；如需高亮后续用 Shiki 按需加载 |
| 格式判断依据 | 前端按扩展名判断 | ListObjectsV2 不返回 Content-Type，额外 HeadObject 增加延迟，扩展名判断对运维场景足够 |

## 二、预览入口

### 2.1 对象行操作按钮

在每个对象行的 hover 浮现操作区，「下载」之前新增「预览」按钮：

```
☐ 📄 config.json  2.1KB  2025-07-15  [预览] [下载] [删除]
                                  ↑ 新增
```

- 仅对**可预览类型**的对象显示「预览」按钮
- 不可预览类型（如 .zip、.exe、.tar.gz）不显示该按钮，避免无效点击

### 2.2 双击预览（快捷操作）

双击对象行也可触发预览（仅可预览类型），降低操作步数：

```
双击 📄 config.json 行:
  -> 如果是可预览类型 -> 打开预览抽屉
  -> 如果不可预览 -> 无操作（避免误触下载）
```

## 三、预览类型与渲染方式

### 3.1 类型判断规则

前端按对象 Key 的扩展名判断类型（与现有 `fileIcon()` 函数复用并扩展）：

| 分类 | 扩展名 | 渲染方式 | 浏览器原生支持 |
|---|---|---|---|
| 图片 | png, jpg, jpeg, gif, svg, webp, ico, bmp | `<img>` | ✅ 全部 |
| 视频 | mp4, webm, ogg | `<video controls>` | ✅ mp4(H.264)/webm/ogg |
| 音频 | mp3, wav, ogg, aac, flac | `<audio controls>` | ⚠️ flac 部分浏览器不支持 |
| PDF | pdf | `<iframe>` | ✅ 大多数现代浏览器 |
| 文本 | txt, json, csv, xml, log, md, js, ts, mjs, css, html, htm, yaml, yml, ini, conf, sh, bat, sql, env, toml | `fetch` + `<pre>` | N/A |
| 其他 | 其余所有 | 不显示预览按钮 | N/A |

### 3.2 可预览判断函数

```typescript
type PreviewType = 'image' | 'video' | 'audio' | 'pdf' | 'text' | null

function getPreviewType(key: string): PreviewType {
  const ext = key.split('.').pop()?.toLowerCase() || ''
  if (['png', 'jpg', 'jpeg', 'gif', 'svg', 'webp', 'ico', 'bmp'].includes(ext)) return 'image'
  if (['mp4', 'webm', 'ogg'].includes(ext)) return 'video'
  if (['mp3', 'wav', 'ogg', 'aac', 'flac'].includes(ext)) return 'audio'
  if (['pdf'].includes(ext)) return 'pdf'
  if (['txt', 'json', 'csv', 'xml', 'log', 'md', 'js', 'ts', 'mjs', 'css', 'html', 'htm', 'yaml', 'yml', 'ini', 'conf', 'sh', 'bat', 'sql', 'env', 'toml'].includes(ext)) return 'text'
  return null
}
```

## 四、预览抽屉（Drawer）

### 4.1 整体布局

```
┌ 对象预览抽屉（从右侧滑出）──────────────────────────┐
│                                                        │
│  [✕]  config.json                              [下载]   │  ← 顶部：文件名 + 下载按钮
│       2.1KB · 2025-07-15 14:32                         │     元信息行
│       人民广场站 / config                              │     目标实例/bucket
│                                                        │
│  ┌──────────────────────────────────────────────────┐ │
│  │                                                    │ │  ← 内容区（按类型渲染）
│  │              [预览内容]                             │ │
│  │                                                    │ │
│  └──────────────────────────────────────────────────┘ │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 4.2 抽屉配置

- **组件**：`NuxtSlideover`（Nuxt UI 侧滑面板，从右侧滑出）
- **宽度**：`w-1/2`（占视口一半，最小 480px，最大 900px）
- **可关闭**：点击遮罩层、按 ESC、点击 ✕ 按钮均可关闭
- **打开动画**：右滑入场 300ms

### 4.3 顶部信息栏

```
[✕]  config.json                              [下载]
     2.1KB · 2025-07-15 14:32
     人民广场站 / config
```

- 左侧：✕ 关闭按钮 + 文件名（Key 最后一段）
- 右侧：下载按钮（复用现有下载逻辑）
- 第二行：文件大小 · 最后修改时间
- 第三行：实例名 / bucket（灰色小字）

## 五、各类型预览渲染

### 5.1 图片预览

```
┌──────────────────────────────────────────────────┐
│                                                    │
│              ┌────────────────┐                   │
│              │                │                   │
│              │     [图片]      │                   │
│              │                │                   │
│              └────────────────┘                   │
│                                                    │
└──────────────────────────────────────────────────┘
```

- `<img :src="previewUrl">` 直接指向 `/api/instances/objects/download?...&inline=1`
- `max-height: 70vh`，图片等比缩放，居中展示
- 支持点击图片放大（可选，第一期不做）

### 5.2 视频预览

```
┌──────────────────────────────────────────────────┐
│                                                    │
│         ┌──────────────────────────┐              │
│         │                          │              │
│         │    <video controls>       │              │
│         │                          │              │
│         └──────────────────────────┘              │
│              ▶  ━━━━━━━━━━━  00:12 / 03:45        │
│                                                    │
└──────────────────────────────────────────────────┘
```

- `<video :src="previewUrl" controls>` 浏览器原生播放器
- `max-height: 70vh`，等比缩放
- 不支持的格式（如 mkv）点击预览前已隐藏按钮

### 5.3 音频预览

```
┌──────────────────────────────────────────────────┐
│                                                    │
│              🎵 recording.mp3                       │
│                                                    │
│         ▶  ━━━━━━━━━━━━━━━  00:12 / 03:45          │
│                                                    │
└──────────────────────────────────────────────────┘
```

- `<audio :src="previewUrl" controls>` 浏览器原生播放器
- 居中展示，上方显示音波图标 + 文件名

### 5.4 PDF 预览

```
┌──────────────────────────────────────────────────┐
│                                                    │
│  ┌──────────────────────────────────────────────┐ │
│  │                                              │ │
│  │            [PDF 内嵌渲染]                     │ │
│  │                                              │ │
│  │            <iframe>                          │ │
│  │                                              │ │
│  └──────────────────────────────────────────────┘ │
│                                                    │
└──────────────────────────────────────────────────┘
```

- `<iframe :src="previewUrl">` 浏览器内置 PDF Viewer 渲染
- `height: 75vh`，全宽展示
- 兜底：如果浏览器无 PDF 插件，iframe 显示空白 -> 底部提示"PDF 预览不可用，请下载查看"

### 5.5 文本预览

```
┌──────────────────────────────────────────────────┐
│                                                    │
│  1  {                                               │
│  2    "name": "miniops",                            │
│  3    "version": "1.0.0",                           │
│  4    "instances": [                                │
│  5      "10.24.0.10:9000"                           │
│  6    ]                                             │
│  7  }                                               │
│                                                    │
└──────────────────────────────────────────────────┘
```

- `fetch(previewUrl)` 获取文本内容，`<pre>` 展示
- **行号**：左侧显示行号（CSS counter 或 split 后 map）
- **等宽字体**：`font-family: monospace`
- **自动换行**：`white-space: pre-wrap; word-break: break-all`（长行不溢出）
- **大小限制**：文件 > 2MB 时不 fetch，展示提示"文件过大（>2MB），请下载后查看"
- **加载态**：fetch 期间显示 spinner
- **二进制误判兜底**：如果 fetch 的内容含大量乱码（非 UTF-8），显示"该文件可能不是文本文件，请下载后查看"。判断方式：fetch 后检测是否含 `\uFFFD`（replacement character）占比过高（>10%）

## 六、预览 URL 构造

### 6.1 内联渲染 URL（图片/视频/音频/PDF）

```
/api/instances/objects/download?instanceId=xxx&bucket=yyy&key=zzz&inline=1
```

后端收到 `inline=1` 时：
- `Content-Disposition: inline`（浏览器内联渲染）
- 不设 `Content-Disposition: attachment`（不触发下载）

### 6.2 文本 fetch URL

文本预览也用同一个 URL，前端 `fetch` 获取 `text/plain` 响应体：

```typescript
const res = await fetch(previewUrl)
const text = await res.text()
```

## 七、加载态与错误处理

### 7.1 各类型加载态

| 类型 | 加载中 | 完成 | 失败 |
|---|---|---|---|
| 图片 | `<img>` 的 `onload` 前显示 spinner | 图片渲染 | `onerror` -> "图片加载失败" + [下载] |
| 视频 | `<video>` 的 `onloadeddata` 前显示 spinner | 播放器就绪 | `onerror` -> "视频加载失败" + [下载] |
| 音频 | `<audio>` 的 `oncanplay` 前显示 spinner | 播放器就绪 | `onerror` -> "音频加载失败" + [下载] |
| PDF | iframe 加载中显示 spinner | PDF 渲染 | iframe 空白 -> 提示下载 |
| 文本 | fetch 中显示 spinner | 文本展示 | fetch 失败 -> "加载失败" + [重试] |

### 7.2 错误场景

```
实例不可达 / 凭据失效:
  -> 预览 URL 请求返回 502
  -> 抽屉内容区显示: "加载失败：<error>"
  -> 提供 [重试] 和 [关闭] 按钮

文件不存在（已被删除）:
  -> 预览 URL 请求返回 404
  -> 提示: "对象不存在，可能已被删除"
  -> 关闭抽屉并刷新列表

文本文件过大（>2MB）:
  -> 不发起 fetch
  -> 直接显示: "文件过大（2.1MB > 2MB），请下载后查看"
  -> 提供 [下载] 按钮
```

## 八、不可预览格式的处理

### 8.1 隐藏预览按钮

`getPreviewType()` 返回 `null` 的对象（如 .zip、.exe、.tar.gz、.db），不显示「预览」按钮，只显示「下载」「删除」：

```
☐ 📁 backup.tar.gz  8.3MB  2025-07-13  [下载] [删除]
                                           ↑ 无预览按钮
```

### 8.2 双击无反应

双击不可预览的对象行，不触发任何操作（避免误触下载）。

## 九、与其他功能的关系

| 关联功能 | 关系 | 说明 |
|---|---|---|
| 对象下载 | 复用 | 预览 URL = 下载 URL + `?inline=1`，后端同一路由 |
| 预签名 URL | 独立 | 预览走后端代理，不用预签名 URL（预签名 URL 的 `Content-Disposition` 不可控） |
| 对象删除 | 独立 | 预览抽屉内有下载按钮，但删除仍回列表行操作（避免预览中误删） |
| 文件图标 | 复用 | 预览类型判断与 `fileIcon()` 的扩展名表部分重叠，可复用 |

## 十、设计要点总结

1. **Drawer 侧抽屉**展示预览内容，宽度大，不影响列表上下文
2. **浏览器原生渲染优先**：图片/视频/音频/PDF 用原生标签，后端零转码
3. **文本安全展示**：fetch 后 `<pre>` 展示，Vue 自动转义防 XSS，2MB 上限
4. **复用 download 路由**：加 `?inline=1` 参数，零新增后端路由
5. **不可预览格式隐藏按钮**：避免无效点击
6. **双击快捷预览**：可预览类型双击行即预览，降低操作步数
7. **顶部信息栏**：文件名 + 大小 + 时间 + 目标实例/bucket + 下载按钮
