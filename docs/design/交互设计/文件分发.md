# 文件分发

- **路由**: `/dispatch`
- **实现**: `app/pages/dispatch/index.vue`、`app/composables/use-dispatch.ts`、`app/components/dispatch/*`

## 布局

```text
┌─────────────┬──────────────────────────────────┐
│  目标实例树   │  文件分发主区                      │
│  (分组/实例)  │  文件列表 或 进度卡片 + 提交栏       │
└─────────────┴──────────────────────────────────┘
```

副文案：「将本地文件/文件夹批量分发到目标 S3 实例」。

## 阶段机

`phase: idle | staging | dispatching | done | cancelled`

| 阶段 | 主区 | 可用操作 |
|------|------|----------|
| idle | 文件列表 + 目标选择 | 添加文件/文件夹、勾选实例、设 bucket/前缀、**开始分发** |
| staging | 暂存进度（逐文件百分比） | **取消暂存** |
| dispatching | 进度卡片（实例折叠） | **后台继续** / **取消** |
| done / cancelled | 结果 + 汇总 | **重试**（失败实例）、**新建分发** |

非 idle 时目标树、添加文件等输入禁用。

## 目标选择

- 实例树：仅 enabled；勾选实例；**分组半选**显示 indeterminate；分组可一键全选
- 每实例一个 bucket：下拉（异步加载，失败可手填）；**组级批量设 bucket**（取组内公共 bucket）
- 全局 **目标前缀** 可选

## 文件列表

- 文件 / 文件夹混选；文件夹聚合为可展开条目（数量 + 总大小 + 状态）
- 同名 `objectKey` 后选覆盖先选
- 移除：idle 可删；分发中不可

## 暂存 → 分发

1. **开始分发**：校验（≥1 暂存成功 + ≥1 目标含 bucket）
2. staging：XHR `POST /api/dispatch/stage`；单文件失败标 ❌，不阻断
3. 全部暂存完成（至少 1 成功）→ `POST /api/dispatch` → 订阅任务
4. 暂存阶段**不能**后台继续（前端 XHR）；分发阶段可

## 进度卡片

- 顶部：总数/成功/失败 + 总进度
- 实例行：完成数、迷你进度、失败数；展开文件明细（✅/❌/⏳/⬜）
- 失败实例（done/cancelled）显示 **重试**：收窄为该实例 + 失败文件，重新暂存并新 taskId

## 取消

- 暂存中：abort XHR，回 idle；已暂存交 TTL
- 分发中：后端取消；未开始文件跳过；完成后状态为 cancelled
