# 任务查看器与暂存管理

顶栏右侧常驻两个入口。

## 任务查看器

覆盖 **分发 / 上传 / 复制 / 移动** 全部长操作。

### 三段式

1. **执行中**：类型 + 进度 + 百分比；可展开实例/文件明细
2. **排队中**：等待执行的任务，可取消
3. **最近完成**：成功/失败/跳过数与时间

### 角标

| 状态 | 表现 |
|------|------|
| 无任务 | 静态图标 |
| 执行中 | 转圈 + 数字 |
| 全部成功 | 变绿，约 3 秒后角标消失 |
| 有失败 | 常驻，手动查看后消失 |

### 行为

- 任务执行与页面无关，可离开再回来
- 取消执行中任务：当前文件跑完，其余标 skipped
- 完成任务在内存保留约 30 分钟（`TASK_RETENTION_SECONDS`），进程重启后丢失

### 部分失败

任务状态 `done` 且 `summary.failed > 0` 即部分失败；单文件失败不会把任务标为 failed。

## 暂存管理

未提交的上传/分发文件会暂存在服务端磁盘。

- **查看**：文件名、大小、时间
- **删除**：单个或清空
- 后端亦有 TTL 孤儿清理（默认 24 小时）

暂存成功但未提交时，靠 TTL 兜底；手动清理更干净。后台孤儿清理周期为 **6 小时**，超 `UPLOAD_TTL_HOURS`（默认 24h）的暂存会被删除。

## 调试

设 `TASK_DELAY_MS` 可人为放慢每个文件，便于观察排队、取消、后台继续。
