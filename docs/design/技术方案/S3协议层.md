# S3 协议层

- **实现**: `server/utils/s3.ts`
- **依赖**: `@aws-sdk/client-s3`（`S3Client` + 各 Command）
- **兼容面**: [reference/S3兼容性.md](../../reference/S3兼容性.md)

对 S3 兼容端点的唯一出口：客户端创建、连通性探测、对象读写删拷。业务层（API / 执行器）不直接使用 AWS SDK。

## 客户端

```ts
createS3Client(instance) → S3Client({
  endpoint: instance.endpoint,
  region: instance.region?.trim() || 'us-east-1',
  credentials: { accessKeyId, secretAccessKey },
  forcePathStyle: true,
})
```

每次调用工厂函数创建客户端（未做长连接池封装）。

## 连通性 `testConnectivity`

1. **探活** `probeLiveness`
   - 请求 `GET {endpoint}/minio/health/live`（5s 超时）
   - 200 → `{ kind: 'minio-health', latency }`
   - 非 2xx / 超时 / 网络错误 → 降级
2. **降级** `ListBuckets`（10s）
   - 成功 → `s3-auth-ok`（在线 + 凭据有效）
   - HTTP 403 / `AccessDenied` → `s3-reachable`（在线、凭据无效）
   - 其他 HTTP 响应（<500）→ 可达
   - 网络错误 → `offline`
3. 结果写入 `ConnectivityResult`：`online` / `latency` / `authValid` / `authError` / `error`

`testGroupConnectivity` 对 enabled 实例 `Promise.all` 并发调用。

## 对象操作

| 函数 | S3 行为 | 要点 |
|------|---------|------|
| `listBucketsWithMeta` | ListBuckets | 返回 name + createdAt |
| `listObjects` | ListObjectsV2 | `delimiter` 可空（递归）或 `/`；单页 `LIST_MAX_KEYS=200`；continuationToken 分页 |
| `getObjectStream` | GetObject | 支持 `Range`；返回 Node Readable + contentType/length/contentRange/etag |
| `uploadObjectStream` | PutObject | Body 为 Buffer/流/Blob；显式 `ContentType` + 可选 `ContentLength` |
| `copyObjectStream` | CopyObject 或 Get+Put | 见下 |
| `deleteObjects` | DeleteObjects | 自动按 1000 分批 |
| `deleteByPrefixes` | 递归列 + 批量删 | `delimiter=''` 列出后走 `deleteObjects` |
| `collectObjectsByPrefixes` | 递归列 | 供 copy/move 展开文件夹；上限 `COPY_MOVE_MAX_OBJECTS` |

## 复制 `copyObjectStream`

- **同 `endpoint`**：`CopyObjectCommand`；`CopySource` 对 key 做 `encodeURIComponent`（中文/特殊字符）
- **跨 endpoint**：GetObject → **读成 Buffer** → PutObject  
  原因：SDK 对 Node Readable 默认 chunked（无 Content-Length），部分 S3 实现拒收

## DeleteObjects 与 Content-MD5

`DeleteObjects` 请求在 `awsAuthMiddleware` 之前用 middleware 为 body 计算并注入 `Content-MD5`（SDK v3 不自动添加）。

## 路径与 Content-Type

- `sanitizeObjectKey`：`\`→`/`、去段首点、过滤空段与 `..`，防路径遍历
- `inferContentType`：扩展名 → MIME 表，未命中 `application/octet-stream`  
  调用方不得使用浏览器上传时的 `file.type`（Bun 会污染 `;charset=utf-8`）

## 错误

`formatS3Error` / `formatExecError`：聚合 `AggregateError.errors[]`（如 ECONNREFUSED 时 message 常为空）。
