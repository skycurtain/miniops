# 实例管理

- **路由**: `/manage`
- **实现**: `app/pages/manage/index.vue`、`app/composables/use-connectivity.ts`

## 布局

- 页头标题「实例管理」，副文案「管理实例组与组内 S3 实例」
- **左栏**：分组列表（名称 + 实例数），选中高亮；「新建分组」
- **主区**：选中分组下的实例表 + 工具（添加实例、连通性测试、导入导出）

## 分组

| 操作 | 交互 |
|------|------|
| 新建 / 编辑 | 弹窗（名称必填，描述可选），成功 toast |
| 删除 | 确认弹窗；**默认组不可删**；删除后选中项就近切换 |
| ⋮ 菜单 | 编辑 / 删除 |

## 实例表

列：名称（可跳转浏览）、Endpoint（等宽小字）、连通性、状态（启用/禁用）。

| 行内操作 | 行为 |
|----------|------|
| 浏览对象 | 跳转 `/browse?instance=<id>`；禁用实例 tooltip「请先启用实例」 |
| 启用/禁用 | 切换 `enabled`，toast 说明结果 |
| 复制 | 同组生成「(副本)」 |
| 删除 | 确认弹窗 |
| 连通性 | 单实例或整组 |

名称超长省略，tooltip 显示全文。

## 实例表单

弹窗字段：名称、服务端点（`http://…`）、Access Key、Secret Key（可切换明文眼睛）、**Region**（可选，placeholder `us-east-1`，help 说明留空默认）、启用开关。  
提交校验走 schema；成功后关闭并刷新表格。

## 连通性展示

| 状态 | 含义 |
|------|------|
| 在线 + 凭据有效 | 正常 |
| 在线 + 凭据无效 | 红/警示（AK/SK 问题） |
| 离线 | 网络或服务不可达 |

整组测试并发；分组行显示汇总。

## 导入 / 导出

- **导出**：下载 JSON 附件（`miniops-groups-export.json`）
- **模板**：下载示例（`miniops-groups-template.json`）
- **导入**：选文件 → 校验失败整批拒绝并提示；成功 toast 显示新增/更新数

## 危险操作

删除分组/实例走统一 `openConfirm` 弹窗（标题 + 说明 + 确认），执行中 loading。
