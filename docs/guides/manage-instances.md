# 实例与分组管理

入口：顶栏 **实例管理**（`/manage`）。

## 概念

- **分组**：实例的组织单位，可折叠；内置「默认」组不可删
- **实例**：一个 S3 兼容端点 + 凭据；`enabled=false` 时不可被浏览/分发选中

## 添加实例

1. 选择分组 → **添加实例**
2. 填写：
   - **实例名称**：列表显示名
   - **服务端点**：`http://host:port`（如 `http://127.0.0.1:9000`）
   - **用户名/密码**：Access Key / Secret Key
   - **Region**（可选）：留空默认 `us-east-1`；AWS S3 按 bucket 区域填写
   - **启用**：开关
3. 保存

## 连通性测试

- 单实例或整组
- 结果含义：
  - **在线**：端点可达（MinIO health 或 ListBuckets 降级）
  - **凭据有效**：Access/Secret 正确
  - 在线但凭据无效：检查 AK/SK
  - 离线：网络/端口/服务未启动

## 维护操作

| 操作 | 说明 |
|------|------|
| 编辑 | 改名称、端点、凭据、region、启用状态 |
| 复制 | 同组生成「(副本)」，便于加同构节点 |
| 启用/禁用 | 禁用后分发/浏览不显示 |
| 删除 | 删实例；删分组会删组内全部实例（默认组除外） |

## 导入 / 导出

- **导出**：下载全量 JSON（含密钥，注意保管）
- **模板**：下载示例 JSON
- **导入**：按 `id` 覆盖；任一实例非法则整批拒绝

## 跳转浏览

实例行 **浏览对象** 进入实例访问（`/browse?instance=<id>`）。
