# 任务与暂存

- **实现**: `app/components/task-viewer-button.vue`、`app/components/staging-manager-button.vue`
- **状态**: `app/composables/use-task-manager.ts`

## 任务查看器（顶栏）

### 入口按钮与角标

| 条件 | 图标/角标 |
|------|-----------|
| 有执行中或排队 | 数字 = active+queue 数量，`info` |
| 未查看失败（含**部分失败**） | `!`，`error` |
| 未查看已取消 | `!`，`warning` |
| 全部成功且未查看 | `✓`，`success`，**约 3 秒后消失** |
| 其他 | 静态图标 |

部分失败 = `status==='failed'` **或** `status==='done' && summary.failed>0`。

### 弹窗结构

1. **执行中**：类型图标/文案 + 进度；可展开明细（手风琴，同时一个）
2. **排队中**：列表，可取消
3. **最近完成**：摘要（成功/失败/跳过）+ 时间；打开或标记查看后消角标

### 行为

- 打开时拉取 active/completed；对 running/queued 任务订阅 SSE
- **取消**：排队移除；执行中等 SSE 终态（保留连接同步 `cancelled`/`skipped`）
- 任务在内存保留约 30 分钟；进程重启后列表为空

## 暂存文件管理（顶栏）

Tooltip「暂存文件管理」→ 弹窗「暂存文件 / 未提交的上传/分发暂存，可手动清理」。

| 操作 | 说明 |
|------|------|
| 列表 | 文件名、大小、时间等 |
| 行删除 | 单条删除，toast |
| **全部清空** | 清空暂存 |
| 空态 | 「没有暂存文件」 |

数据来自 `GET /api/staging`，删除走 `DELETE /api/staging`。

## 后台继续语义

任务与 SSE 解绑：关掉上传/分发弹窗或离开页面后，任务继续；顶栏查看器可随时查看、取消。
