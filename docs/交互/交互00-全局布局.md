# 全局布局交互设计

> 本文记录 V1 版本的整体页面布局方案，基于 MVP 经验改进。

## 1. 应用外壳

### 1.1 布局结构

整个应用采用 Nuxt UI Dashboard 布局，由侧边栏 + 主面板组成：

```
┌──────────┬──────────────────────────────────────────────┐
│ 侧边栏    │  顶部导航栏（标题 + 副标题 + 主题切换按钮）   │
│          ├──────────────────────────────────────────────┤
│ ▸ Logo   │                                              │
│          │                                              │
│ ▸ 导航    │              页面内容区（可滚动）             │
│          │                                              │
│          │                                              │
│          │                                              │
│ ▸ 折叠    │                                              │
└──────────┴──────────────────────────────────────────────┘
```

### 1.2 侧边栏

使用 `NuxtDashboardSidebar` 组件，配置 `collapsible` + `resizable`：

| 配置项         | 值     | 说明                       |
| -------------- | ------ | -------------------------- |
| `collapsible`  | `true` | 可折叠（拖到边缘自动收起） |
| `resizable`    | `true` | 可拖拽调整宽度             |
| `min-size`     | `12`   | 最小宽度占比               |
| `default-size` | `16`   | 默认宽度占比               |

侧边栏分为三个区域：

- **header**：Logo + 应用名称（`miniops`）。折叠时只显示 Logo 图标。
- **default**：导航菜单（`NuxtNavigationMenu` vertical）。折叠时自动隐藏文字，鼠标悬停显示 popover tooltip。
- **footer**：折叠按钮（`NuxtDashboardSidebarCollapse`）。点击切换折叠/展开状态。

### 1.3 顶部导航栏

使用 `NuxtDashboardNavbar`，位于主面板的 header 区：

| 区域                | 内容                                             |
| ------------------- | ------------------------------------------------ |
| `#leading`          | 副标题文字（如"MinIO 批量运维平台"），仅大屏可见 |
| `#default`（title） | 当前页面标题                                     |
| `#right`            | 主题切换按钮（`NuxtColorModeButton`）            |

> **注意**：主题切换按钮放在顶部导航栏右侧，不是侧边栏。

### 1.4 内容区

使用 `NuxtDashboardPanel` 的 `#body` slot，内容区可独立滚动。各页面将内容放在 `#body` 中。

**重要**：内容区不使用 `NuxtContainer`（它会限制最大宽度），直接铺满整个 `#body`。

### 1.5 导航结构

V1 的导航项：

```
实例管理      -> /manage
实例访问      -> /browse
```

两个顶级导航项，不含子菜单。后续如有新功能（批量分发等）再加子菜单或新顶级项。

导航菜单使用 `NuxtNavigationMenu`，配置 `popover` + `tooltip` 实现折叠态的悬停提示。

## 2. 页面内容区布局模式

### 2.1 页头模式

每个页面的顶部统一采用"左标题 + 右操作"的页头布局：

```
┌──────────────────────────────────────────────────────┐
│ 页面标题                              [操作按钮组]    │
│ 副标题描述                                            │
└──────────────────────────────────────────────────────┘
```

> 各页面的具体操作按钮和交互细节见对应的交互文档（交互01、交互02）。

- 左侧：`h1` 标题（`text-2xl font-bold text-highlighted`）+ 副标题描述（`text-muted`）。
- 右侧：操作按钮组，`flex items-center gap-2`。
- 标题和操作区用 `flex items-center justify-between gap-4` 布局。
- 页头下方与内容区之间用 `flex flex-col gap-6` 间距。

### 2.2 内容滚动

页面内容放在 `NuxtDashboardPanel` 的 `#body` slot 中，该 slot 自带 `overflow-y: auto` 滚动。页面内部不需要额外处理滚动。

### 2.3 全宽铺满

内容区不使用 `NuxtContainer`，直接铺满整个主面板宽度。页面内容用 `flex flex-col gap-6` 纵向排列。
